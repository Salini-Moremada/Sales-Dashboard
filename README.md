# Sales-Dashboard
# 📊 Sales Dashboard Project

## Overview
This project presents an **interactive sales dashboard** that provides insights into revenue, profit, and quantity across multiple dimensions such as region, state, category, sub-category, and customer segment.  
The dashboard enables stakeholders to make **data-driven decisions** by visualizing trends and performance metrics.

---

## Features
- **KPI Tracking**: Total revenue, profit, and quantity displayed for quick overview.
- **Time-Based Analysis**: Yearly and quarterly trends for sales and profit.
- **Regional Insights**: State and city-level breakdowns with geographic mapping.
- **Category & Sub-Category Analysis**: Bubble charts and treemaps for product performance.
- **Segment Analysis**: Consumer, Corporate, and Home Office contribution comparison.
- **Interactive Filters**: Drill-down by year, category, state, and sub-category.

---

## Tools & Technologies
- **Power BI / Tableau** – Dashboard creation and visualization  
- **Excel** – Data cleaning and preprocessing  
- **Python (Pandas, Matplotlib, Seaborn)** – Advanced analysis and visualization  

---

## Dataset
- Sales data from 2014–2017  
- Includes attributes: Order Date, Category, Sub-Category, Region, State, City, Segment, Sales, Profit, Quantity  

---

## Visualizations
- Line charts for sales/profit trends  
- Pie charts for segment and category contribution  
- Maps for regional sales distribution  
- Treemaps and bubble charts for sub-category analysis
